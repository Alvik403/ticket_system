# Определения метрик

Все отметки времени формирует API в UTC. Часовой пояс площадки применяется
только при отображении и формировании суточных срезов.

## Талон

- Ожидание: `IN_SERVICE.occurredAt - CREATED.occurredAt`.
- Обработка: `COMPLETED.occurredAt - IN_SERVICE.occurredAt`.
- Полный цикл: `COMPLETED.occurredAt - CREATED.occurredAt`.
- Неявка: финальное событие `NO_SHOW`; не смешивается с завершёнными.
- Отмена: финальное событие `CANCELLED`; не смешивается с завершёнными.
- Переназначение: каждое назначение считается отдельно, а талон — один раз.

## Сотрудник

- Завершено: число его активных назначений с финальным `COMPLETED`.
- Среднее время: арифметическое среднее длительности обработки.
- Медиана: p50 длительности обработки; основная метрика типичного времени.
- p90: 90% завершённых обслуживаний короче этого значения.
- В SLA: доля завершённых обслуживаний, чья длительность не превышает
  `ServiceType.slaSeconds`.
- Загрузка: время состояния `BUSY` / длительность закрытой смены. В MVP
  события смены хранятся, расчёт добавляется после согласования правил пауз.

Незавершённые интервалы не подставляются как нули. Отчёт должен показывать
период, фильтры, количество наблюдений и отдельно перечислять исключения.
Персональные показатели сотрудников доступны только роли `ADMIN` и
аудитируются при экспорте.
